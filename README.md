# 🌸 창원여자고등학교 1학년 3반 종합 알림판

창원여자고등학교 1학년 3반 학생들과 담임 선생님을 위한 **여고생 감성 맞춤형 종합 알림판** 웹 애플리케이션입니다.

👉 **웹사이트 접속**: [https://byeongjunpark.github.io/cwgh2026103/](https://byeongjunpark.github.io/cwgh2026103/)

---

## 🎀 주요 기능

1. **📢 메인 대시보드**
   - 오늘의 주요 공지사항 & 알림장
   - 실시간 D-Day 카운트다운 (시험, 축제, 소풍, 방학)
   - 창원여고 맛있는 오늘 급식 메뉴
   - 학교 공식 홈페이지 및 리로스쿨 바로가기

2. **🕒 1-3반 시간표**
   - 월~금 1~7교시 과목 안내
   - 현재 시각 기준 진행 중인 교시 **실시간 하이라이트 (NOW ⏰)**
   - 교실 게시판용 인쇄 기능 지원

3. **📅 학사일정 & D-Day**
   - 중간/기말고사, 학력평가, 체험학습, 방학 일정 뷰어

4. **🎂 3반 생일판**
   - 반 친구들의 월별 생일 카운트다운
   - 🎉 **생일 축하 버튼** 클릭 시 파스텔 폭죽(Canvas Confetti) 애니메이션!

5. **🙋‍♀️ 1인 1역할 담당자 표**
   - 반장, 부반장, 칠판, 우유, 환기, 기자재 등 역할 검색 및 담당자 명단
   - 교실 인쇄용 포맷 지원

6. **📝 수행평가 알림장**
   - 과목별 수행평가 항목, 제출 기한, 상세 제출법 정리

7. **📊 구글 시트 데이터 연동**
   - 선생님과 반장이 구글 시트에서 작성한 내용을 웹 알림판에 즉시 반영!
   - [1-3반 구글 시트 수정하기](https://docs.google.com/spreadsheets/d/16tH6lwRXZxxcW0vfiZxZwbYWEjbTNHsThj5J86WwbPQ/edit)
